# نقشهٔ راه Hesabyar 2.0

**وضعیت:** کاربر `Hesabyar2` را به‌عنوان source greenfield و Shared Core را به‌عنوان هدف سطح‌بالا انتخاب کرد؛ ADR-001 در PR #12 به main رسید و همچنان پیش‌نویس است، نه تصمیم مصوب. PR #11 با `f13e3d9` و PR #12 با `6211365` ادغام شدند؛ شاخهٔ فعال نشست `arena/4085f085-hesabyar2` روی merge commit #12 است. CI روی mergeهای #11/#12 موفق است (`41939981854`, `42004918329`)، اما branch protection/required-check در این مرحله تغییر یا مستقلاً تأیید نشده و مالک باید آن را روشن کند. هر دو merge به‌طور خودکار GitHub Pages build/deploy را اجرا کردند (`41939981195`, `42004917176` موفق)؛ محتوای صفحه بررسی نشده است. بنا بر درخواست کاربر، Pages deploy دیگری بدون مجوز جداگانه انجام نمی‌شود.

## گیت‌های تغییر

- ادامهٔ greenfield UI mock در شاخهٔ فعال `arena/4085f085-hesabyar2` مجاز است. PR #11 و PR #12 در main ادغام شده‌اند؛ کاربر جداگانه فقط helper خالص WP‑1 را با قرارداد مشخص ورودی صریح ریال/تومان، عدد صحیح مثبت، حفظ remainder بدون گردکردن و رقم فارسی/لاتین مجاز کرده؛ helper به فروش، ledger یا persistence وصل نیست.
- اصلاح `voidInvoice`، ثبت/ابطال/refund واقعی، ledger، سیاست‌های دیگر پول/rounding، HMAC/licensing، schema migration، persistence/backend، entitlement، import از `KarenYar` یا production deployment همچنان به approval/spec جداگانه نیاز دارند.
- هر مرحله باید بر source دقیق، diff و آزمون واقعی استوار باشد؛ تست‌های داخلی source repo صرفاً شواهد کمکی‌اند، نه جایگزین اجرای جاری.
